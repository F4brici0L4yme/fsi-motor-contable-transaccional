# Stack tecnológico

Decision tomada por votación entre tribus del ERP. Todo el equipo del módulo **Motor Contable Transaccional** debe seguir este stack; no se admiten alternativas sin una nueva votación registrada en `docs/`.

| Capa | Tecnología |
| :--- | :--- |
| Backend | Python + Django REST Framework (DRF) |
| Frontend | React + Vite + TypeScript |
| Base de datos | PostgreSQL |
| Estilos | Tailwind CSS |
