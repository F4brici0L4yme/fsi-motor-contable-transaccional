# Definition of Done (DoD)

Una tarea o historia de usuario se considera terminada solo si cumple **todos** estos puntos.

## Para cualquier tarea

- [ ] El código fue revisado en un Pull Request con al menos **1 aprobación**.
- [ ] El autor no aprobó su propio PR.
- [ ] Las conversaciones del PR están resueltas.
- [ ] El PR no tiene conflictos con `develop`.
- [ ] El cambio fue probado (pruebas automáticas y/o verificación manual documentada).
- [ ] La documentación afectada está actualizada (`docs/`, comentarios de API, diccionario de datos).
- [ ] Los criterios de aceptación del issue están marcados como cumplidos.
- [ ] No se agregaron secretos, credenciales ni archivos generados al repositorio.
- [ ] El tablero refleja el estado **Terminado**.

## Para historias de usuario (adicional)

- [ ] Los criterios de aceptación fueron validados por QA.
- [ ] La historia fue **aceptada por el Product Owner**.
- [ ] Si toca tablas o contratos compartidos, el acuerdo con el otro módulo está documentado en `docs/dependencias-entre-modulos.md` o `docs/tablas-compartidas.md`.

## Para tareas técnicas (adicional)

- [ ] El entregable descrito en el issue existe y es verificable.
- [ ] El revisor asignado confirmó el entregable.
